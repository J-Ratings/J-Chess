J-Chess

Play Info Examples

Rules

The rules of J-Chess are simple. All chess rules apply except:

  • The back rank is randomised symmetrically.
  • The only constraint is that the Bishops must be on opposite colour squares. The King does not need to be between the rooks.
  • There is no castling.

J-Chess² follows the same rules, except the back ranks are randomised independently for each side.

How Many Positions?

There are 2,880 possible back rank arrangements for one side. When you press the J-Chess button, one of these layouts is chosen and used for both players, giving 2,880 possible starting positions.

Since both sides share the same setup, practically all of these positions are fair. White usually has a small advantage like in standard chess.

In J-Chess², each side’s back rank is randomised separately.
That makes 2,880 × 2,880 = 8,294,400 possible combinations in total.

However, not every position is balanced. When tested with Stockfish, about 1 in 4 of these positions were found to be roughly fair. That makes around 2 million fair J-Chess² positions.

When you press the J-Chess² button, it only uses these fair positions, not all 8 million.

Why I Made This

I’m not keen on deep opening memorisation. I prefer pattern recognition that you can use in completely different positions. Chess960 helps, but you can still prepare a small set of openings if you put a lot of effort in. If it is possible, the top players will do it. In J-Chess there are 3x as many possible possitions as 960 making memorising harder. Castling is also quite complicated for beginners to learn, especially in 960. I find no-castling chess extremely exciting, so these two points combined made me remove the castling rule entirely.

Here the sheer number of balanced starting positions makes prep pointless. Dropping castling and using the same randomised back rank for both sides keeps the game fair. J-Chess², on the other hand, randomises each back rank independently. This makes sure that the kings don’t always face each other. Without castling this would result in lack of opposite-side castling-like positions. With independent randomising, the kings can be in completely different locations or both tucked away safely.

Each side has different pros and cons. That’s what I like about J-Chess. You never know what position you’ll get. You have to make the most of what you’ve been given, knowing that the starting setup is roughly equal.
